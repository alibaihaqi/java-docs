# Java Intermediate

[Hub](https://alibaihaqi.github.io/learning-docs/) › Java › Intermediate

## What you'll build

You extend the beginner `GET /items` endpoint from a fixed list into a full CRUD
API backed by a database. Using Spring Data JPA over an in-memory H2 database you
add `GET /items`, `GET /items/{id}`, and `POST /items`, with a service layer,
bean validation, error handling, and MockMvc + repository tests.
